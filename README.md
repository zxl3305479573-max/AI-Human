# AI-Human 数字人平台

AI-Human 是一个数字人平台项目，目标是让用户通过可视化配置与对话交互，快速生成并驱动属于自己的数字人形象与人格。

## 项目简介

数字人平台围绕「形象 + 声音 + 人格 + 交互」四个核心要素构建：

- **形象**：管理数字人的外貌素材与形象设定，支持不同风格的数字人角色。
- **声音**：为数字人配置音色与语音合成能力。
- **人格**：通过人设、背景、说话风格等设定，让数字人具备稳定一致的表达方式。
- **交互**：支持文本、语音等多模态对话，并驱动数字人进行实时反馈。

## 核心功能规划

> 以下为规划中的功能范围，会随着开发进度持续更新。

- 数字人角色管理：创建、编辑、删除数字人，维护角色基本信息与形象设定。
- 人格配置：编辑人设提示词、性格标签、知识范围与说话风格。
- 对话能力：接入大模型，支持多轮上下文对话与流式输出。
- 语音能力：语音合成输出，为数字人提供声音表现。
- 形象驱动：将文本或语音结果与数字人形象绑定，呈现可交互的虚拟形象。
- 会话记录：保存历史对话，便于回看与继续会话。
